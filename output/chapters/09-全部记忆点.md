# 全部记忆点

这一章只放闭卷考试需要背熟的定义、公式和常见判断。复习时可以把它当成最后一轮背诵清单。

## 基础知识与残差网络

\begin{keybox}
\begin{itemize}
\item 参数是网络中需要学习的数，常见参数包括权重 $W$ 和 bias $b$。
\item 单个神经元常写成 $z=w^Tx+b$，再经过激活函数得到输出。
\item 全连接层可写成 $y=\sigma(Wx+b)$；若输入维度为 $d_{\mathrm{in}}$、输出维度为 $d_{\mathrm{out}}$，则 $W\in\mathbb{R}^{d_{\mathrm{out}}\times d_{\mathrm{in}}}$。
\item ReLU 公式是 $\operatorname{ReLU}(x)=\max(0,x)$，提供非线性能力。
\item Sigmoid 输出在 0 到 1 之间，常用于表示比例或门控。
\item Softmax 把分数变成概率分布，所有概率之和为 1；大的更大、小的更小，结果更接近 one-hot。
\item Softmax 公式：$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$。
\item 交叉熵中，真实类别预测概率越高，loss 越小；单个样本可记为 $L=-\log p_k$。
\item 深层普通网络可能遇到梯度消失、梯度爆炸和退化问题；网络更深不一定更容易训练。
\item 残差连接基本形式是 $y=x+F(x)$，帮助信息和梯度在深层网络中传播。
\item ResNet 主要缓解深层网络训练困难和退化问题，不是单纯用于减少参数或解决过拟合。
\end{itemize}
\end{keybox}

## 卷积神经网络 CNN

\begin{keybox}
\begin{itemize}
\item 图像具有局部关联性和一定不变性；CNN 的设计正是为了利用这些图像特征。
\item 图像不具有置换不变性；完全打乱像素顺序会破坏空间结构。
\item 指数衰减下降较快，幂级数衰减下降较慢；幂级数衰减可看作许多指数衰减成分的叠加。
\item 卷积的核心是局部窗口加权求和；卷积核和 bias 都是可训练参数。
\item Padding 在边缘补值，用来控制输出空间大小；Same Padding 可保持空间尺寸不变。
\item Stride 是卷积核滑动步长；stride 越大，输出空间尺寸通常越小。
\item 多通道卷积中，一个完整卷积核覆盖所有输入通道；卷积核个数就是输出通道数 $C_{\mathrm{out}}$。
\item 单个输出通道：$Y_j=\sum_{c=1}^{C_{\mathrm{in}}} X_c*K_{j,c}+b_j$。
\item 卷积输出形状：输入 $H\times W\times C_{\mathrm{in}}$，输出 $H_{\mathrm{out}}\times W_{\mathrm{out}}\times C_{\mathrm{out}}$。
\item 输出空间尺寸：$H_{\mathrm{out}}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1$，$W_{\mathrm{out}}=\left\lfloor\frac{W+2P-K}{S}\right\rfloor+1$。
\item 卷积参数量：无 bias 为 $K\times K\times C_{\mathrm{in}}\times C_{\mathrm{out}}$；有 bias 时再加 $C_{\mathrm{out}}$。
\item 池化汇总局部信息、降低空间尺寸，通常没有可学习参数，也通常不改变通道数。
\item 最大池化取窗口最大值，平均池化取窗口平均值，GAP 把每个通道压成一个数。
\item CNN 没有唯一固定格式；卷积、激活、池化、展平、全连接、softmax 等模块可灵活组合。
\end{itemize}
\end{keybox}

## RNN、LSTM 与文本处理

\begin{keybox}
\begin{itemize}
\item 文本数据是离散符号序列，词语顺序、上下文和长程依赖都很重要。
\item Tokenization 是把文本切成 token；token 可以是词、子词、字符或特殊符号。
\item One-hot 高维稀疏，本身不表达词义相似性；embedding 低维稠密，可以通过训练学习语义关系。
\item Embedding 可理解为 one-hot 向量乘以可训练矩阵 $E\in\mathbb{R}^{|\mathcal{V}|\times d}$。
\item Next Token Prediction 是根据前文预测下一个 token，标签来自文本中的下一个 token。
\item RNN 通过隐藏状态逐步处理序列，并在不同时间步共享同一组参数，因此可以处理可变长度序列。
\item RNN 隐藏状态公式：$S_t=f(Ux_t+WS_{t-1}+b)$。
\item RNN 输出公式：$\hat{y}_t=g(VS_t+b_y)$。
\item BPTT 是随时间反向传播；长序列中容易出现梯度消失或梯度爆炸。
\item 截断 BPTT 只向前回看有限步数，用来降低长序列完整反传的计算和显存开销。
\item LSTM 是改进的 RNN，通过记忆状态和门控机制控制信息保留、写入和输出，缓解长程依赖问题。
\item LSTM 三条设计原则：信息使用前先做可学习线性变换；控制比例的门用 sigmoid；提取候选信息常用 tanh。
\end{itemize}
\end{keybox}

## Transformer

\begin{keybox}
\begin{itemize}
\item RNN/LSTM 按时间步串行处理 token；Transformer 可并行处理 token，但需要位置编码提供顺序信息。
\item 原始 Transformer 是 encoder-decoder 结构；现在常见生成式大语言模型多用 decoder-only。
\item Embedding 矩阵随机初始化并可训练；位置编码提供 token 位置信息。
\item 注意力四步：输入线性映射得到 $Q,K,V$；用 $QK^T$ 算相关性；softmax 得注意力权重；用权重对 $V$ 加权求和。
\item 缩放点积注意力公式：$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$。
\item $Q$ 是 Query，$K$ 是 Key，$V$ 是 Value；$Q$ 和 $K$ 的最后一维必须相同，$V$ 的维度可以不同。
\item Causal mask 保证预测当前位置时不能看到未来 token。
\item Block 中 attention 负责 token 之间交互；FNN 逐 token 作用；LayerNorm 逐 token 计算。
\item LayerNorm 有可训练参数 $\gamma,\beta$。
\item 输出投影层把隐藏向量映射到词表维度；贪婪解码取最大概率 token，采样解码具有随机性。
\item Transformer 整体流程：输入 token -> Embedding + 位置编码 -> 多层 block -> 输出投影 -> Softmax。
\end{itemize}
\end{keybox}

## 训练现象

\begin{keybox}
\begin{itemize}
\item 低频表示变化慢、平滑、整体轮廓；高频表示变化快、振荡、细节或噪声。
\item 频率原则也叫 spectral bias：神经网络通常先拟合低频，再拟合高频。
\item 频率原则可解释为什么神经网络常先学整体规律，而不是一开始就记住高频噪声。
\item Early stopping 可以在模型进一步拟合高频噪声前停止训练，从而改善泛化。
\item 图像分类中的频率更常指分类函数的响应频率，不是图像像素内部的频率。
\item 初始化大小会影响训练路径和最终解；参数不能全部初始化为 0。
\item 对一维输入，$\operatorname{ReLU}(wx+b)$ 的转折点是 $x=-\frac{b}{w}$。
\item 参数凝聚指小初始化下，同层神经元出现趋同偏好，多个神经元可能等效为较少有效神经元。
\item 凝聚后的大网络可能像小网络，但大网络参数更多、下降方向更多，通常更容易训练。
\item 平坦解指参数附近一片区域损失都较低；尖锐解指参数稍微改变损失就明显上升。
\item 平坦解通常对噪声和参数扰动更鲁棒，泛化往往更好。
\item 小批量训练、合理较大的学习率、Dropout 都可能帮助找到更平坦的解。
\end{itemize}
\end{keybox}

## 大模型

\begin{keybox}
\begin{itemize}
\item 大模型又称基础模型，通常参数量大、数据规模大，并能适应多种下游任务。
\item 大语言模型以 token 为输入输出；多模态数据也可以类似语言一样 token 化。
\item Encoder-only 看双向上下文，适合理解任务，代表 BERT。
\item Decoder-only 使用 causal mask，只看当前及之前 token，适合生成任务，代表 GPT、Llama、DeepSeek。
\item Encoder-Decoder 先编码输入再解码输出，适合翻译等输入输出都需要建模的任务。
\item 预训练学基础能力；微调/SFT 用特定数据继续训练；提示词工程通常不更新参数。
\item 强化学习后训练可用于增强推理能力，也可用于对齐人类偏好。
\item 知识蒸馏让 Student model 学习 Teacher model 的能力，常用于降低部署成本。
\item Scaling law 描述规模、数据、算力增加时测试损失通常按幂律下降。
\item 涌现能力指模型规模增大到一定程度后，某些能力从接近随机水平跃升到明显更好。
\item 上下文学习不更新参数；思维链输出中间推理步骤；幻觉是看似合理但实际错误的生成内容。
\end{itemize}
\end{keybox}

## 强化学习

\begin{keybox}
\begin{itemize}
\item 强化学习是决策型任务，智能体通过与环境交互和奖励反馈学习。
\item 强化学习目标是最大化期望累计奖励，而不是匹配每一步的标注标签。
\item 状态是环境完整信息，观察是智能体实际看到的信息；观察可能只是状态的一部分。
\item 动作空间可以是离散的，也可以是连续的；奖励可以是正的，也可以是负的。
\item 折扣回报为 $G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots$；$\gamma$ 越大越重视长期奖励。
\item 情节型任务有终止状态，连续型任务没有固定终止状态。
\item 探索是尝试未知动作获取信息；利用是根据已有知识选择当前较优动作。
\item 马尔可夫性指未来状态分布只依赖当前状态，而不依赖更早历史。
\item MDP 是 Markov Decision Process，常包含状态、动作、转移概率、奖励和折扣因子。
\item 策略 $\pi(a|s)$ 是状态到动作选择的规则；价值函数 $V^\pi(s)$ 衡量从状态出发的期望回报。
\item Bellman 方程的直观含义是当前价值等于当前奖励加折扣未来价值；矩阵形式是 $V=R+\gamma PV$。
\item DP 通常需要环境模型和转移概率；MC 通过采样估计价值，随机性较大。
\item 深度强化学习用神经网络近似价值函数或策略；DQN 用神经网络拟合 $Q$ 值。
\item RLHF 用人类偏好构造奖励信号，让大模型输出更符合人类偏好和价值观。
\end{itemize}
\end{keybox}
