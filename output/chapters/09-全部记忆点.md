# 全部记忆点

这一章按闭卷考试来背，不做名词堆叠。每条尽量记成三件事：它用来回答什么问题、核心表述是什么、常见判断哪里容易错。

## 公式怎么背

\begin{keybox}
\begin{itemize}
\item \textbf{Softmax：} 用来把一组 logits 变成概率。
$$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$$
其中 $z_i$ 是第 $i$ 类分数，$p_i$ 是第 $i$ 类概率。所有 $p_i$ 相加为 1；分数大的类概率更大，整体更接近 one-hot。
\item \textbf{交叉熵：} 用来衡量预测概率和真实标签的差异。二分类中，若 $y_i\in\{0,1\}$，$f_\theta(x_i)$ 是预测为正类的概率：
$$H(y,p)=-\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log f_\theta(x_i)+(1-y_i)\log(1-f_\theta(x_i))\right]$$
更 general 的多分类形式为：
$$H(y,p)=-\frac{1}{n}\sum_{i=1}^{n}\sum_{c=1}^{C}y_{i,c}\log p_{i,c}$$
其中 $C$ 是类别数，$y_{i,c}$ 是 one-hot 标签，$p_{i,c}$ 是第 $c$ 类预测概率。真实类别概率越大，loss 越小。
\item \textbf{残差连接：} 用来保留原输入信息，缓解深层网络训练困难。
$$y=x+F(x)$$
其中 $x$ 是输入，$F(x)$ 是残差分支学习到的变化量。
\end{itemize}
\end{keybox}

\begin{keybox}
\begin{itemize}
\item \textbf{卷积输出尺寸：} 用来计算卷积后高和宽。
$$H_{\mathrm{out}}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1,\qquad
W_{\mathrm{out}}=\left\lfloor\frac{W+2P-K}{S}\right\rfloor+1$$
其中 $H,W$ 是输入空间尺寸，$K$ 是卷积核大小，$P$ 是 padding，$S$ 是 stride。输出通道数不是由这个公式算出，而是由卷积核个数决定。
\item \textbf{卷积参数量：} 用来计算一个卷积层有多少可学习参数。
$$\#\mathrm{params}=K^2C_{\mathrm{in}}C_{\mathrm{out}}+C_{\mathrm{out}}$$
其中 $C_{\mathrm{out}}$ 是卷积核个数，也是输出通道数；最后的 $C_{\mathrm{out}}$ 是 bias。参数量不乘 $H_{\mathrm{out}}$ 和 $W_{\mathrm{out}}$。
\item \textbf{多通道卷积：} 用来说明一个输出通道怎样由所有输入通道共同算出。
$$Y_j=\sum_{c=1}^{C_{\mathrm{in}}}X_c*K_{j,c}+b_j,\qquad j=1,\ldots,C_{\mathrm{out}}$$
这里 $*$ 表示在空间维度上做卷积运算；$j$ 是输出通道编号，$c$ 是输入通道编号。$X_c$ 是第 $c$ 个输入通道，$K_{j,c}\in R^{K\times K}$ 是第 $j$ 个 filter 在第 $c$ 个输入通道上的卷积核切片；完整的第 $j$ 个 filter 形状为 $K\times K\times C_{\mathrm{in}}$。一个 filter 产生一个输出通道；有 $C_{\mathrm{out}}$ 个 filter 就有 $C_{\mathrm{out}}$ 个输出通道。
\end{itemize}
\end{keybox}

\begin{keybox}
\begin{itemize}
\item \textbf{RNN 状态更新：} 用来说明当前隐藏状态同时依赖当前输入和历史信息。
$$S_t=f(Ux_t+WS_{t-1}+b),\qquad y_t=g(VS_t+c)$$
$U,W,V,b,c$ 在所有时间步共享，所以序列变长时参数量不随时间步增加；同一个 RNN 单元可以重复更多步，因此可以处理变长序列。
\item \textbf{Scaled Dot-Product Attention：} 用来让一个 token 根据相关性汇总其他 token 的信息。
$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
$Q,K,V$ 由输入表示 $X$ 分别乘三个可训练矩阵得到；$Q$ 用来查询，$K$ 用来匹配，$V$ 是被汇总的信息。$QK^T$ 计算关联强度，$\sqrt{d_k}$ 用来缩放，softmax 得到注意力权重，最后对 $V$ 加权求和。
\end{itemize}
\end{keybox}

\begin{keybox}
\begin{itemize}
\item \textbf{ReLU 转折点：} 用来判断一维 ReLU 神经元在哪个输入位置发生折线变化。
$$x=-\frac{b}{w}$$
若多个神经元转折点相同，它们在函数形状上可以合并理解；不同转折点提供不同非线性位置。
\item \textbf{折扣回报：} 用来累计未来奖励。
$$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots$$
$\gamma=0$ 时只看眼前奖励；$\gamma$ 越接近 1，越重视长期奖励。
\item \textbf{Bellman 方程：} 用来把当前价值和未来价值联系起来。
$$V=R+\gamma PV$$
$V$ 是价值向量，$R$ 是奖励向量，$P$ 是转移矩阵，$\gamma$ 是折扣因子。DP 通常需要知道转移概率。
\item \textbf{Scaling law：} 用来描述规模、数据、算力增加时，测试损失通常按幂律下降。
$$L(N)=\left(\frac{N_c}{N}\right)^{\alpha_N},\qquad
L(D)=\left(\frac{D_c}{D}\right)^{\alpha_D},\qquad
L(C)=\left(\frac{C_c}{C}\right)^{\alpha_C}$$
这里记住“幂律关系”：规模继续增大通常还能降低 loss，但收益会逐渐变小。
\end{itemize}
\end{keybox}

## 基础与残差网络

\begin{keybox}
\begin{itemize}
\item \textbf{单个神经元：} 基础计算是 $z=w^Tx+b$，其中 $w$ 是权重，$b$ 是 bias；再经过激活函数得到输出。
\item \textbf{参数：} 神经网络中通过训练学习的量，典型是权重 $W$ 和偏置 $b$；bias 不是手工常数，而是可学习参数。
\item \textbf{激活函数：} 用来提供非线性。没有非线性时，多层线性变换整体仍等价于一个线性变换。
\item \textbf{ReLU：} $\operatorname{ReLU}(x)=\max(0,x)$，负数变 0，正数保持不变。
\item \textbf{Sigmoid：} 输出范围在 $0$ 到 $1$ 之间，常用来表示门控开关或概率倾向。
\item \textbf{Softmax 与交叉熵：} Softmax 先把分数变成概率，交叉熵再惩罚真实类别概率太小的情况。
\item \textbf{深层网络困难：} 深度增加后可能出现梯度消失、梯度爆炸和退化。退化指层数更深但训练效果反而变差。
\item \textbf{残差连接：} 让网络学习 $F(x)$ 而不是完整映射，输出写成 $x+F(x)$；它保留原信息，使深层网络更容易训练。
\end{itemize}
\end{keybox}

## 卷积神经网络 CNN

\begin{keybox}
\begin{itemize}
\item \textbf{图像局部关联性：} 相邻像素关系强，距离越远关系越弱；CNN 用局部卷积窗口利用这一特点。
\item \textbf{幂律衰减：} 可以看成许多指数衰减的叠加，因此图像中可能仍有较慢衰减的长程关联。
\item \textbf{图像不变性：} 图像任务常希望对平移、旋转、缩放有一定鲁棒性；但图像像素顺序不能随便打乱。
\item \textbf{CNN 与 MLP 区别：} MLP 通常全连接，参数多且忽略空间局部结构；CNN 使用局部连接和参数共享，参数更少，更适合图像。
\item \textbf{卷积核：} 卷积核是可训练的小窗口权重，同一个卷积核在整张图上滑动，这就是参数共享。
\item \textbf{输出通道数：} 一个 filter 产生一个输出通道；filter 个数通常就是 $C_{\mathrm{out}}$。
\item \textbf{Padding：} 通过补边控制输出大小和边缘信息，不引入可学习参数。
\item \textbf{Stride：} stride 是滑动步长；stride 越大，输出空间尺寸越小。stride 为 2 的卷积可以实现可学习下采样，也就是在卷积提取特征的同时完成类似 pooling 的降采样。
\item \textbf{池化：} 池化通常没有可学习参数，用来下采样并汇总局部信息。Max pooling 取最大值，Mean pooling 取平均值。
\item \textbf{$1\times1$ 卷积：} 主要用于改变通道数或进行通道间线性组合，不改变空间邻域大小。
\item \textbf{CNN 结构：} 卷积、激活、池化、全连接等层可以灵活搭配，不存在必须固定照抄的网络格式。
\end{itemize}
\end{keybox}

## RNN 与 LSTM

\begin{keybox}
\begin{itemize}
\item \textbf{文本数据特点：} 文本是离散符号序列，长度可变，并且有顺序、上下文、语法结构和长程依赖。
\item \textbf{为什么需要 RNN：} MLP/CNN 更适合固定大小输入或局部结构；RNN 按时间步处理序列，并用隐藏状态保存历史。
\item \textbf{RNN 处理可变长度的核心：} 同一组参数在所有时间步共享，序列变长只增加计算步数，不增加模型参数量。
\item \textbf{数据质量：} 数据越多通常越好，但高质量、去重、过滤偏见/隐私/有害内容的数据更稳定、更省算力。
\item \textbf{Tokenization：} 把文本切成 token。输入是原始文本，输出是 token 序列；常见方法有 BPE、WordPiece、Unigram。
\item \textbf{One-hot 与 embedding：} One-hot 高维稀疏，只表示编号；embedding 低维稠密、可训练，能承载语义相似性。
\item \textbf{Embedding 矩阵：} 若词表大小为 $|\mathcal{V}|$，embedding 维度为 $d$，矩阵大小为 $|\mathcal{V}|\times d$；one-hot 乘这个矩阵得到对应词向量。
\item \textbf{Next Token Prediction：} 用前面的 token 预测下一个 token，标签来自文本本身，因此属于自监督学习；训练常用交叉熵。
\item \textbf{生成过程：} 模型一步生成一个 token，再把生成结果接回输入，直到生成 SEP 或达到长度限制；可用贪婪解码或采样。
\item \textbf{BPTT：} RNN 训练时沿时间展开后的网络反向传播；长链式相乘容易导致梯度消失或爆炸，实际可用截断 BPTT 只回看有限步。
\item \textbf{LSTM：} LSTM 是改进的 RNN，用记忆状态和门控缓解长程依赖问题。
\item \textbf{LSTM 三个门：} 遗忘门决定保留多少旧记忆，输入门决定写入多少新信息，输出门决定输出多少记忆信息；遗忘门 $f_t\in(0,1)$，越接近 1，旧记忆和梯度越容易保留。
\item \textbf{LSTM 常见设计原则：} 先做线性变换；sigmoid 适合做门，因为输出在 $0$ 到 $1$；tanh 适合产生候选信息，因为输出可正可负。
\item \textbf{Encoder-Decoder RNN：} 先编码输入序列，再解码输出序列，可处理输入输出长度不同的任务。
\end{itemize}
\end{keybox}

## Transformer

\begin{keybox}
\begin{itemize}
\item \textbf{RNN/LSTM 局限：} token 需要串行处理，长依赖仍难；Transformer 允许序列中 token 并行输入、并行输出。
\item \textbf{位置编码：} 注意力机制本身不关心顺序，所以必须给 token 加入位置信息；位置编码不改变词表大小。
\item \textbf{Embedding + Position：} embedding 表示 token 语义，position encoding 表示位置，两者相加后作为 Transformer 输入。
\item \textbf{Q、K、V：} Q 是 Query，表示当前 token 要查什么；K 是 Key，表示其他 token 可被匹配的标识；V 是 Value，表示真正被汇总的信息。
\item \textbf{Q/K/V 维度：} K 和 V 的数量必须相同，也就是第一维相同，因为每个 key 要对应一个 value；Q 和 K 的最后一维必须相同，才能做点积；Q 的数量可以和 K/V 不同，也就是第一维可以不同。
\item \textbf{注意力四步：} 先线性变换得到 Q/K/V；再用 QK 点积算关联强度；再 softmax 得到注意力权重；最后用权重对 V 加权求和。
\item \textbf{Causal mask：} 在生成任务中遮住未来 token，保证当前位置只能看自己和过去，不能提前看到答案。
\item \textbf{LayerNorm：} 以单个 token 的特征维度为单位归一化，不在 token 之间计算均值方差；有可训练的 $\gamma,\beta$。
\item \textbf{FFN：} Transformer 中的 FFN 是逐 token 的 MLP，参数在位置间共享；token 之间的信息交互主要发生在 attention 中。
\item \textbf{输出投影：} 最后把隐藏向量映射到词表大小，再用 softmax 得到下一个 token 的概率。
\item \textbf{解码方式：} 贪婪解码每步取最大概率 token；采样解码按概率抽样，因此同一输入可能有不同输出。
\end{itemize}
\end{keybox}

## 训练现象：频率、凝聚、平坦性

\begin{keybox}
\begin{itemize}
\item \textbf{过参数化问题：} 神经网络参数很多，能表达复杂函数，但训练仍常得到有规律、可泛化的解；这与优化和结构带来的隐式偏置有关。
\item \textbf{傅里叶级数直觉：} 函数可看成不同频率成分的叠加。低频变化慢、平滑；高频变化快、振荡、细节多。
\item \textbf{频率原则：} 神经网络训练通常先学习低频成分，再学习高频成分，也叫 spectral bias。
\item \textbf{控制变量理解：} 判断“先低频还是先高频”时，应比较同幅值、不同频率的成分，而不是把幅值影响和频率影响混在一起。
\item \textbf{图像分类中的频率：} 通常讨论分类函数/响应函数的频率，而不是图像像素自身的频率；高响应频率表示微小输入扰动就可能改变输出。
\item \textbf{早停：} 如果噪声或过细节信息偏高频，早停可以在模型充分学习低频主结构后，减少对高频噪声的拟合。
\item \textbf{初始化影响：} 初始化影响初始参数、初始函数和训练路径；全零初始化会让神经元对称，通常不可取。
\item \textbf{ReLU 凝聚：} 小初始化下，同层 ReLU 神经元的方向和转折点可能趋同，等效为更少的有效神经元。
\item \textbf{为什么不用小网络代替：} 凝聚后的大网络可近似等效小网络，但大网络的训练路径更容易优化，直接训练小网络不一定同样容易。
\item \textbf{平坦解：} 参数附近一片区域 loss 都低，扰动后仍稳定，通常泛化更好。
\item \textbf{尖锐解：} 低 loss 区域很窄，参数轻微变化 loss 就明显上升，通常更不稳定。
\item \textbf{小批量与大学习率：} 小批量梯度噪声有助于跳出尖锐区域；合理较大的学习率更容易得到平坦解，但学习率太大会导致震荡甚至不收敛。
\end{itemize}
\end{keybox}

## 大模型

\begin{keybox}
\begin{itemize}
\item \textbf{基础模型：} 用大规模数据训练、可迁移到多种任务的大模型，是后续微调和应用的基础。
\item \textbf{LLM：} 大语言模型以文本 token 为主要输入输出，核心训练目标常是 next token prediction。
\item \textbf{Encoder-only：} 双向看上下文，代表是 BERT，适合理解类任务；不适合只能看过去 token 的自回归生成。
\item \textbf{Decoder-only：} 使用 causal mask，只看当前位置及以前 token，代表是 GPT、Llama、DeepSeek，是当前生成模型主流结构。
\item \textbf{Encoder-Decoder：} 编码器处理输入，解码器生成输出，常用于翻译、摘要等输入输出都明确的任务。
\item \textbf{预训练：} 用海量文本学习通用语言和知识能力，代价高，是大模型能力来源之一。
\item \textbf{SFT：} 监督微调用标注指令数据继续训练，让模型更会按任务要求回答。
\item \textbf{RL 后训练：} 用奖励或人类偏好继续优化，可增强推理和对齐；它不是用来取代预训练，也不是直接缩短响应时间。
\item \textbf{知识蒸馏：} Teacher 模型提供输出或行为，Student 模型模仿它，用于压缩和部署。
\item \textbf{提示词工程：} 改输入提示，不更新模型参数；上下文学习也是在不更新参数的情况下利用示例完成任务。
\item \textbf{思维链：} 让模型输出中间推理步骤，常用于复杂推理。
\item \textbf{涌现：} 模型规模增大到某个范围后，某些能力可能从弱到强突然显现。
\item \textbf{幻觉与偏见：} 幻觉是模型生成看似合理但错误的内容；偏见是输出中存在系统性倾向。
\end{itemize}
\end{keybox}

## 强化学习

\begin{keybox}
\begin{itemize}
\item \textbf{强化学习：} 决策型任务，智能体通过动作影响环境，根据奖励反馈学习策略，目标是最大化期望累计奖励。
\item \textbf{与监督学习区别：} 监督学习依赖标注标签；强化学习依赖奖励反馈，奖励可能延迟出现。
\item \textbf{状态与观察：} 状态是环境完整信息；观察是智能体实际看到的信息，可能只是状态的一部分。
\item \textbf{动作空间：} 智能体可选动作集合，可以是离散的，也可以是连续的。
\item \textbf{情节型与连续型：} 情节型任务有终止状态；连续型任务没有固定终止状态。
\item \textbf{探索与利用：} 探索是尝试未知动作获取信息；利用是选择当前认为最优的动作。只利用可能错过长期更优选择。
\item \textbf{马尔可夫性：} 给定当前状态后，未来状态分布只依赖当前状态，而不依赖更早历史。
\item \textbf{随机性转移：} 给定当前状态和动作后，下一状态仍可能按概率分布变化，不一定唯一确定。
\item \textbf{MDP：} 常包含状态、动作、转移概率、奖励和折扣因子，是强化学习问题的标准形式化。
\item \textbf{策略：} $\pi(a|s)$ 表示在状态 $s$ 下选择动作 $a$ 的规则；最优策略使期望累计奖励最大。
\item \textbf{价值函数：} $V^\pi(s)$ 表示在策略 $\pi$ 下从状态 $s$ 出发的期望回报。
\item \textbf{策略评估与改进：} 评估是估计当前策略的价值；改进是根据价值更新策略。
\item \textbf{DP 与 MC：} DP 通常需要环境模型和转移概率；MC 通过多次采样取平均，不一定需要知道转移概率，但方差较大。
\item \textbf{深度强化学习：} 用神经网络近似价值函数或策略；DQN 用神经网络替代表格拟合 $Q$ 值。
\item \textbf{RLHF：} 用人类偏好构造奖励信号，使大模型输出更符合人类偏好和价值观。
\end{itemize}
\end{keybox}
