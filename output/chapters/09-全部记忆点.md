# 全部记忆点

这一章按“闭卷背诵”来写。每条尽量背成：概念名 + 关键词。先背公式，再背定义，再背常见判断。

## 必背公式

\begin{keybox}
\begin{itemize}
\item 神经元：$z=w^Tx+b$。
\item 全连接层：$y=\sigma(Wx+b)$。
\item ReLU：$\operatorname{ReLU}(x)=\max(0,x)$。
\item Softmax：$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$。
\item 交叉熵：$L=-\log p_k$。
\item 残差连接：$y=x+F(x)$。
\item 卷积输出：$H_{\mathrm{out}}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1$。
\item 卷积参数量：$K^2C_{\mathrm{in}}C_{\mathrm{out}}+C_{\mathrm{out}}$。
\item 多通道卷积：$Y_j=\sum_c X_c*K_{j,c}+b_j$。
\item RNN：$S_t=f(Ux_t+WS_{t-1}+b)$。
\item Attention：$\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$。
\item ReLU 转折点：$x=-\frac{b}{w}$。
\item 折扣回报：$G_t=R_{t+1}+\gamma R_{t+2}+\gamma^2R_{t+3}+\cdots$。
\item Bellman：$V=R+\gamma PV$。
\item Scaling law：$L(N)=\left(\frac{N_c}{N}\right)^{\alpha_N}$，$L(D)=\left(\frac{D_c}{D}\right)^{\alpha_D}$，$L(C)=\left(\frac{C_c}{C}\right)^{\alpha_C}$。
\end{itemize}
\end{keybox}

## 基础与残差

\begin{keybox}
\begin{itemize}
\item 参数：可学习的 $W,b$。
\item Bias：可学习的偏置。
\item 激活函数：提供非线性。
\item Sigmoid：输出 $0$ 到 $1$。
\item Softmax：分数变概率。
\item 交叉熵：真类概率越大，loss 越小。
\item 深层网络困难：梯度消失、梯度爆炸、退化。
\item 退化：层数加深，效果反而变差。
\item 残差连接：保留原信息。
\item ResNet：缓解深层训练困难。
\end{itemize}
\end{keybox}

## CNN

\begin{keybox}
\begin{itemize}
\item 图像特点：局部关联、不变性。
\item 图像顺序：不能乱打乱。
\item CNN 核心：局部连接、参数共享。
\item 卷积：局部窗口加权求和。
\item 卷积核：可训练参数。
\item Padding：控制边缘和输出大小。
\item Same padding：空间大小不变。
\item Stride：滑动步长。
\item Stride 越大：输出越小。
\item 输出通道数：卷积核个数。
\item $1\times 1$ 卷积：改通道数。
\item 池化：降空间尺寸。
\item Max pooling：取最大值。
\item Mean pooling：取平均值。
\item GAP：每个通道变一个数。
\item CNN 结构：层可灵活组合。
\end{itemize}
\end{keybox}

## RNN 与 LSTM

\begin{keybox}
\begin{itemize}
\item 文本：离散序列。
\item 文本特点：顺序、上下文、长程依赖。
\item Tokenization：文本切成 token。
\item One-hot：高维、稀疏。
\item Embedding：低维、稠密、可训练。
\item Embedding 矩阵：$|\mathcal{V}|\times d$。
\item NTP：预测下一个 token。
\item RNN：按时间步处理。
\item RNN 核心：隐藏状态 + 参数共享。
\item 参数共享：能处理可变长度。
\item BPTT：沿时间反向传播。
\item 长序列问题：梯度消失、梯度爆炸。
\item 截断 BPTT：只回看有限步。
\item LSTM：改进 RNN。
\item LSTM 核心：记忆状态 + 门控。
\item 遗忘门：保留旧记忆。
\item 输入门：写入新信息。
\item 输出门：输出记忆信息。
\item LSTM 三原则：线性变换、sigmoid 门、tanh 候选。
\end{itemize}
\end{keybox}

## Transformer

\begin{keybox}
\begin{itemize}
\item RNN：串行。
\item Transformer：并行。
\item 并行问题：没有天然顺序。
\item 位置编码：提供顺序。
\item Embedding：token 变向量。
\item Q：Query，查询。
\item K：Key，匹配。
\item V：Value，被汇总信息。
\item $Q,K$：最后一维必须相同。
\item 注意力权重：softmax 后得到。
\item Causal mask：不能看未来。
\item Attention：token 间交互。
\item FNN：逐 token 作用。
\item LayerNorm：逐 token 归一化。
\item 输出投影：映射到词表大小。
\item 贪婪解码：取最大概率。
\item 采样解码：有随机性。
\end{itemize}
\end{keybox}

## 训练现象

\begin{keybox}
\begin{itemize}
\item 低频：慢变化、平滑、轮廓。
\item 高频：快变化、振荡、细节。
\item 频率原则：先低频，后高频。
\item Spectral bias：频率原则。
\item 早停：少拟合高频噪声。
\item 分类函数频率：输出对输入扰动的敏感程度。
\item 初始化：影响训练路径。
\item 全零初始化：通常不行。
\item 参数凝聚：同层神经元趋同。
\item 凝聚效果：等效小网络。
\item 大网络优势：更容易优化。
\item 平坦解：附近损失也低。
\item 尖锐解：扰动后损失升高。
\item 平坦解：更鲁棒，泛化更好。
\item 小批量：噪声大，易跳出尖锐解。
\item 大学习率：尖锐区域易震荡。
\end{itemize}
\end{keybox}

## 大模型

\begin{keybox}
\begin{itemize}
\item 大模型：基础模型。
\item 基础模型：大参数、大数据、多任务。
\item LLM：文本 token 输入输出。
\item Encoder-only：双向上下文。
\item Encoder-only 代表：BERT。
\item Decoder-only：causal mask。
\item Decoder-only 代表：GPT、Llama、DeepSeek。
\item Encoder-Decoder：输入编码，输出解码。
\item 预训练：学基础能力。
\item 微调/SFT：特定数据继续训练。
\item 提示词工程：改输入，不改参数。
\item RL 后训练：推理增强、偏好对齐。
\item 知识蒸馏：Teacher 教 Student。
\item Scaling law：幂级数下降。
\item 涌现：规模到阈值后能力跃升。
\item 上下文学习：不更新参数。
\item 思维链：输出中间推理。
\item 幻觉：貌似合理但错误。
\item 偏见：系统性倾向。
\end{itemize}
\end{keybox}

## 强化学习

\begin{keybox}
\begin{itemize}
\item 强化学习：决策型任务。
\item 智能体：做动作。
\item 环境：给奖励和新状态。
\item 学习信号：奖励反馈。
\item 目标：最大化期望累计奖励。
\item 状态：环境完整信息。
\item 观察：智能体看到的信息。
\item 动作空间：可选动作集合。
\item 奖励：可正可负。
\item $\gamma$ 越小：越重眼前。
\item $\gamma$ 越大：越重长期。
\item 情节型：有终点。
\item 连续型：无固定终点。
\item 探索：试未知动作。
\item 利用：用已有最优。
\item MDP：马尔可夫决策过程。
\item 马尔可夫性：未来只依赖当前状态。
\item 策略：选动作规则。
\item 价值函数：期望回报。
\item Bellman：当前价值 = 当前奖励 + 折扣未来价值。
\item DP：需要转移概率。
\item MC：采样取平均。
\item DRL：神经网络近似价值或策略。
\item DQN：神经网络拟合 $Q$ 值。
\item RLHF：人类偏好作奖励。
\end{itemize}
\end{keybox}
