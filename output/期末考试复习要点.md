## 三、分章节考点

## 1. 残差网络基础

### 必会概念

1. 深层普通网络不一定比浅层网络好，可能出现退化问题。
2. 退化问题指网络加深后，训练误差和测试误差可能反而变差。
3. 深层网络训练可能出现梯度消失、梯度爆炸等问题。
4. 残差连接让网络学习 F(x) + x，而不是只学习 F(x)，有助于训练更深网络。
5. 如果额外层暂时学不到有用特征，残差结构也更容易近似恒等映射。
6. 残差连接有助于信息和梯度在深层网络中传播。

### 可出题点

1. 填空：残差连接的基本形式是 F(x) + x。
2. 判断：残差连接一定会增加大量额外参数。错误，典型残差连接本身不一定增加参数。
3. 填空：ResNet 主要用于缓解深层网络的退化问题和梯度传播困难。
4. 判断：深层普通网络一定比浅层普通网络更容易训练。错误。

## 2. 卷积神经网络 CNN

### 必会概念

1. 图像具有局部关联性：相邻像素通常更相关。
2. 图像任务常具有不变性，例如物体轻微平移后类别不变。
3. CNN 的核心模块包括卷积层、池化层、全连接层和输出层。
4. 卷积层使用卷积核提取局部特征，如边缘、方向、纹理。
5. 卷积核参数是可学习的，通常随机初始化后通过训练得到。
6. Padding 用于控制卷积后特征图大小，常用于避免尺寸过快变小。
7. Stride 表示卷积核滑动步长，stride 越大，输出空间尺寸通常越小。
8. 多通道卷积中，卷积核要覆盖输入的所有通道。
9. 输出通道数由卷积核个数决定。
10. 池化可以降低空间尺寸，扩大后续神经元的感受范围；最大池化取局部窗口最大值。
11. 池化通常不改变通道数。
12. 展平是把多维特征图变成向量，送入全连接层。
13. Softmax 将输出变成类别概率分布。

### 简单计算

1. 单通道输入尺寸为 H x W，卷积核尺寸为 K_h x K_w，padding 为 P_h/P_w，stride 为 S_h/S_w，输出尺寸：
   - H_out = floor((H + 2P_h - K_h) / S_h) + 1
   - W_out = floor((W + 2P_w - K_w) / S_w) + 1
2. 若输入通道数为 C_in，卷积核大小为 K_h x K_w，卷积核个数为 C_out，则输出通道数为 C_out。
3. 不考虑 bias 时，卷积层参数量为 K_h x K_w x C_in x C_out。
4. 若考虑 bias，参数量为 K_h x K_w x C_in x C_out + C_out。
5. 最大池化输出尺寸也按窗口大小、padding、stride 用同类公式计算；池化不改变通道数。

### 可出题点

1. 填空：CNN 中输出通道数由卷积核个数决定。
2. 判断：池化层通常会改变通道数。错误。
3. 选择：padding 的主要作用是控制输出尺寸、保留边缘信息。
4. 填空：RGB 图片有 3 个输入通道。
5. 判断：卷积核的参数通常是人为固定的。错误，通常可训练。

## 3. 循环神经网络 RNN 与 LSTM

### 必会概念

1. NLP 的目标是让计算机理解、生成和处理自然语言。
2. 自然语言是离散符号序列，具有上下文相关性和长程依赖。
3. 分词/词元化把文本切分为 token。
4. BPE 从基础符号开始，不断合并高频相邻 token。
5. One-hot 编码维度高、稀疏，不直接表达词义相似性。
6. Word embedding 把 token 映射成可训练的低维稠密向量。
7. Next Token Prediction 是根据前文预测下一个 token。
8. RNN 适合处理序列，因为当前输出可以依赖历史状态。
9. Encoder-Decoder 可处理输入输出不等长任务，如机器翻译。
10. BPTT 是随时间反向传播，用于训练 RNN。
11. RNN 长序列训练容易出现梯度消失和梯度爆炸。
12. LSTM 引入记忆状态和门控机制，缓解长程依赖问题。
13. LSTM 的门使用 sigmoid 控制比例；候选信息常用 tanh 提取。
14. LSTM 的遗忘门、输入门、输出门只是形象命名。
15. LSTM 与 ResNet 类似，都有帮助信息/梯度传播的结构。

### 可出题点

1. 填空：RNN 的训练常用 BPTT，即随时间反向传播。
2. 判断：RNN 完全不会出现梯度消失。错误。
3. 选择：LSTM 引入门控机制的主要目的之一是缓解长程依赖问题。
4. 填空：Next Token Prediction 的目标是预测下一个 token。
5. 判断：One-hot 编码天然能表示“study”和“learn”语义更接近。错误。

## 4. Transformer

### 必会概念

1. Transformer 最初用于序列翻译，核心是注意力机制。
2. 相比 RNN，Transformer 更适合并行计算，也更善于捕捉全局关系。
3. Token 先经过 embedding 变成向量。
4. 位置编码用于告诉模型 token 的位置信息。
5. 注意力机制分两步：计算 token 间关联强度，再按关联强度加权求和。
6. Q、K、V 分别表示 Query、Key、Value，由输入向量经过线性变换得到。
7. Q 和 K 用于计算关联强度，V 提供被加权汇总的信息。
8. Softmax 用于把注意力分数归一化成权重。
9. Decoder 中使用 causal mask，使当前位置不能看到未来 token。
10. 注意力结果后通常接线性变换、残差连接和 LayerNorm。
11. LayerNorm 是逐 token 做归一化。
12. FNN 在 Transformer 中是逐个 token 通过同一个前馈全连接网络。
13. 输出投影层把隐藏向量映射到词表大小，再经 softmax 得到下一个 token 的概率。
14. 贪婪解码取概率最大的 token；采样解码按概率分布抽样。

### 可出题点

1. 填空：Transformer 注意力机制中的 Q、K、V 分别是 Query、Key、Value。
2. 判断：Decoder 在生成下一个 token 时可以看到未来 token。错误。
3. 选择：causal mask 的作用是阻止模型利用未来信息。
4. 填空：位置编码的作用是提供 token 的位置信息。
5. 判断：Transformer 只能处理文本，不能处理图像。作为本课非阅读主线不建议考；若考概念，答案为错误。

## 5. 频率原则

### 必会概念

1. 过参数化网络参数量可能大于样本量，但实际常常仍有较好泛化。
2. 隐式偏好是指损失函数没有显式规定，但训练过程倾向于找到某类解。
3. 频率可以理解为函数变化快慢：低频更平滑，高频更振荡、细节更多。
4. 频率原则：神经网络训练通常先学习低频成分，再学习高频成分。
5. 在图像拟合中，常表现为先学轮廓，再学细节。
6. 低频通常对整体拟合影响更大，高频常与细节或噪声相关。
7. 早停可以在模型尚未充分拟合高频噪声前停止训练，从而提高泛化。
8. 图像分类中的“响应频率”强调输入微小变化对输出的影响，不完全等同于图像本身的空间频率。

### 可出题点

1. 填空：频率原则指神经网络通常先拟合低频，再拟合高频。
2. 判断：早停可能有助于防止模型拟合噪声。正确。
3. 选择：低频通常对应更平滑的函数变化。
4. 判断：高频永远是不重要的信息。错误，高频也可能包含有用细节。

## 6. 参数凝聚与解的平坦性

### 必会概念

1. 初始化大小会影响神经网络训练过程和最终解。
2. 大初始化容易产生更随机、更复杂的函数形状，也更容易过拟合。
3. 小初始化下，同层神经元可能形成相似偏好，这称为凝聚现象。
4. 凝聚后的多个相似神经元可等效为较少的有效神经元。
5. 过参数化大网络发生凝聚时，表达上可能等效于小网络，但训练过程更容易优化。
6. 不能把所有参数都初始化为 0，否则对称性无法打破，训练会失败或很困难。
7. 平坦解指参数扰动后损失变化较小的解。
8. 尖锐解指参数稍微变化损失就显著上升的解。
9. 平坦解通常更鲁棒，泛化更好。
10. 小批量训练、合理较大学习率、Dropout 往往有助于找到更平坦的解。

### 可出题点

1. 填空：小初始化下，同层神经元趋向相似偏好的现象称为参数凝聚。
2. 判断：所有参数初始化为 0 是训练深度网络的好方法。错误。
3. 选择：平坦解相比尖锐解通常泛化更好。
4. 判断：过参数化大网络一定严重过拟合。错误。

## 7. 大模型介绍

### 必会概念

1. 大模型又称基础模型，通常参数量大，经过大规模数据训练，可适应多种下游任务。
2. 大语言模型是最早展现通用智能特征的大模型之一。
3. Encoder 能利用上下文信息；Decoder 只能利用当前和前文信息。
4. Encoder-only 适合理解任务，如 BERT。
5. Decoder-only 适合生成任务，如 GPT、Llama、DeepSeek 系列。
6. Encoder-Decoder 常用于输入输出都需要建模的任务，如翻译，代表模型有 BART、T5。
7. 当前生成式大语言模型主流是 Decoder-only。
8. 预训练通常用大规模数据进行 Next Token Prediction。
9. 微调是在预训练模型基础上，用特定任务数据继续训练。
10. 强化学习后训练可用于增强推理能力或进行人类价值对齐。
11. 提示词工程通过设计输入提示改善模型输出。
12. 知识蒸馏把大模型知识迁移到小模型中。
13. Scaling law 指在一定范围内，模型规模、数据量、计算量与测试损失之间呈现规律关系。
14. 上下文学习指模型不更新参数，仅通过任务描述和少量示例适应新任务。
15. 思维链提示引导模型生成中间推理步骤，有助于复杂推理任务。
16. 幻觉是模型生成貌似事实但实际错误的信息。
17. 大模型可能带有偏见。

### 可出题点

1. 填空：大模型通常又称基础模型。
2. 判断：Decoder-only 模型在生成任务中很常见。正确。
3. 选择：BERT 是 Encoder-only 架构的代表。
4. 填空：上下文学习不需要更新模型权重。
5. 判断：大模型永远不会产生幻觉。错误。

## 8. 强化学习

### 必会概念

1. 强化学习是决策型任务，智能体在动态环境中采取动作，获得奖励，并学习最大化累计奖励。
2. 预测型任务通常根据数据预测输出；强化学习强调交互、试错、奖励和长期回报。
3. 状态 State 是环境完整信息；观察 Observation 是智能体实际能看到的信息，可能只是状态的一部分。
4. 完全可观测环境中，观察与状态一致；部分可观测环境中，观察不完整。
5. 动作空间包括离散动作空间和连续动作空间。
6. 奖励是环境对动作好坏的反馈。
7. 回报是从当前时刻开始的未来奖励总和，常加入折扣因子。
8. 折扣因子 gamma 满足 0 <= gamma <= 1，用于降低远期奖励权重。
9. 强化学习基本循环：状态 -> 动作 -> 奖励和下一状态 -> 再选择动作。
10. 情节型任务有起点和终点，如棋类、关卡游戏；连续型任务没有固定终点，如股票交易、自动驾驶。
11. 探索是尝试未知动作获取信息；利用是根据已知信息选择当前看起来最好的动作。
12. 策略是状态到动作选择的规则或概率分布。
13. 最优策略能最大化期望累计奖励。
14. 基于策略的方法直接学习动作选择；基于价值的方法学习状态或动作的价值，再据此决策。
15. MDP 遵循马尔可夫性：未来状态只依赖当前状态和动作，不依赖更早历史。
16. 价值函数 V(s) 衡量从状态 s 出发，在某策略下能获得的期望回报。
17. 最优价值函数对应最优策略。
18. Bellman 方程刻画当前状态价值与下一状态价值之间的递推关系。
19. 动态规划可以精确计算价值，但通常需要知道环境转移概率。
20. 蒙特卡洛方法通过多次实验采样取平均，简单但方差可能大。
21. 深度强化学习用深度神经网络近似价值函数或策略，能处理高维复杂状态。
22. DQN 用神经网络替代表格来拟合 Q 值。
23. 深度强化学习常见应用包括游戏 AI、机器人控制、自动驾驶、推荐系统、数据中心节能、大模型后训练等。

### 简单公式

1. 无折扣累计奖励：G_t = R_{t+1} + R_{t+2} + ...
2. 折扣累计奖励：G_t = R_{t+1} + gamma R_{t+2} + gamma^2 R_{t+3} + ...
3. Bellman 方程的直观形式：当前价值 = 当前奖励 + 折扣后的未来价值。
4. 不考虑动作时，向量形式可写为：V = R + gamma P V。

### 可出题点

1. 填空：强化学习的目标是最大化期望累计奖励。
2. 判断：强化学习只关心当前奖励，不关心未来奖励。错误。
3. 选择：探索是尝试未知动作，利用是使用已有知识最大化奖励。
4. 填空：MDP 的中文名是马尔可夫决策过程。
5. 判断：动态规划不需要知道环境模型或转移概率。错误。
6. 选择：DQN 使用深度神经网络近似 Q 值。

## 四、适合期末题型的命题方向

### 选择题

适合考“哪个说法正确/错误”“哪个模块对应哪个功能”“哪个方法适合哪个任务”。

1. CNN 中 padding、stride、pooling、channel 的作用。
2. RNN、LSTM、Transformer 的区别。
3. Encoder-only、Decoder-only、Encoder-Decoder 的适用任务。
4. 频率原则、早停、凝聚、平坦解的概念辨析。
5. 大模型中的预训练、微调、蒸馏、提示词工程。
6. 强化学习中的状态、动作、奖励、策略、价值函数、探索利用。

### 判断题

适合考容易混淆的说法。

1. 池化层通常不改变通道数。
2. Decoder 生成时不能看未来 token。
3. LSTM 完全解决了所有长程依赖问题。
4. 早停可以降低拟合高频噪声的风险。
5. 小初始化可能带来凝聚现象。
6. 平坦解通常更鲁棒。
7. 大模型不会产生幻觉。
8. 强化学习的奖励可以是正的，也可以是负的。
9. MDP 的未来状态只和当前状态、动作有关。
10. 蒙特卡洛方法通过采样估计价值。

### 填空题

适合考关键名词和极简单公式。

1. CNN 的输出通道数由卷积核的个数决定。
2. RGB 图像有 3 个通道。
3. Transformer 注意力机制中的 Q、K、V 分别表示 Query、Key、Value。
4. Next Token Prediction 是预测下一个 token。
5. RNN 训练常用 BPTT。
6. MDP 是马尔可夫决策过程。
7. 强化学习的目标是最大化期望累计奖励。
8. 折扣因子 gamma 的取值范围是 0 到 1。
9. 频率原则指神经网络通常先学习低频，再学习高频。
10. 大模型也常被称为基础模型。

## 五、两节复习课建议安排

### 第一节：神经网络结构主线

1. 10 分钟：全连接网络和残差网络基础。
2. 25 分钟：CNN，重点讲结构、padding/stride/channel/pooling、简单尺寸计算。
3. 20 分钟：RNN 和 LSTM，重点讲序列、BPTT、梯度问题、门控记忆。
4. 25 分钟：Transformer，重点讲 embedding、位置编码、QKV、mask、输出层。
5. 10 分钟：用 8-10 道选择/判断快速检测。

### 第二节：训练现象、大模型、强化学习

1. 20 分钟：频率原则、早停、初始化、凝聚、平坦解。
2. 20 分钟：大模型基本概念、架构类型、预训练/微调/蒸馏/提示词、幻觉偏见。
3. 35 分钟：强化学习基本循环、状态/动作/奖励、探索利用、MDP、价值函数、Bellman、DP/MC/DRL。
4. 15 分钟：填空题和易错判断题串讲。

## 六、出题难度建议

1. 避免复杂证明和长公式推导。
2. CNN 计算题可以有，但只考单层输出尺寸、输出通道数、简单参数量。
3. Transformer 不建议考矩阵维度复杂推导，只考 Q/K/V、mask、位置编码、softmax 的作用。
4. RNN/LSTM 不建议考门控公式，只考门控思想和缓解梯度问题。
5. 训练现象只考直觉，不考 Fourier/Hessian 公式。
6. 强化学习只考 Bellman 方程直观含义和最简单形式，不考 TD、Sarsa、Q-learning 推导。
