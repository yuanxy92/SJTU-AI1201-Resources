# 复习提纲整理工作流程

本流程参考“卷积神经网络 CNN”和“循环神经网络 RNN 与 LSTM”两章的整理方式，用于后续章节持续统一风格。

## 1. 先确定本章复习重点

1. 先通读本章 PDF，按课件顺序列出知识点，不打乱上课时已经形成的逻辑顺序。
2. 先总结本章“应该考什么、应该讲什么”，必要时先发给老师确认，再进入正式改稿。
3. 每章开头写出本章复习主线，让学生知道这一章从哪里讲到哪里。
4. 对每个知识点判断它在考试中的角色：
   - 必须掌握：概念、公式、结构、典型计算。
   - 理解即可：帮助串起逻辑的背景知识。
   - 不展开：阅读材料、复杂推导、过细实现细节。

## 2. 正文组织方式

1. 正文按“大知识点 -> 小知识点”展开，避免把所有内容堆成一串列表。
2. 概念部分用简洁句子讲清楚“是什么、为什么、有什么用”。
3. 对比关系要用表格讲清楚，例如 MLP/CNN/RNN、one-hot/embedding、贪婪解码/采样解码。
4. 章节层级最多保留到二级标题；如果某个三级标题只是“示意”“例子”“公式”这类提示，就改成正文中的粗体标签。
5. 容易混淆的内容放到正文对比、表格或例子中讲，不在每个小节反复写“易错点”。
6. 涉及计算或公式时，只保留考试会用到的最简单形式，并配一个小例子。
7. 公式如果是考试重点，要在正文中单独列出，并解释每个符号的含义。

## 3. 定义、例子与关键记忆

1. 重要概念用定义框强调，格式为“概念名：一句话定义”，不要再额外写“定义：”。
2. 例子统一放进绿色例子框，避免普通正文和例子混在一起。
3. 同一小节里出现多个例子时，按出现顺序写成“例子 1、例子 2、例子 3”。
4. 例子标题要说明用途，例如“参数量计算”“padding 保持大小”“stride 让尺寸减小”。
5. 章末只保留一个“关键记忆”，用红色背景收束本章最重要内容；不要在每个知识点下面都写关键记忆。

## 4. 图示选择与插入

1. 判断哪些知识点必须配图：网络结构、数据流、计算过程、模块关系、门控机制、mask、注意力、容易混淆的操作。
2. 图示优先级：
   - 优先从课件 PDF 截图。
   - 课件没有合适图时，再考虑网络资料。
   - 网络资料也不合适时，再调用文生图生成简洁示意图。
3. 截图放在正文对应知识点附近，不集中堆到章末。
4. 图前或图后要用一两句话说明这张图帮助学生看懂什么。
5. 如果整页截图信息过密，要在正文中把最重要的结论单独写出来，不能只依赖图。
6. 如果图示不必要，就用简洁表格或文本示意，不强行放图。

## 5. 章末统一收束

1. 每章末尾统一放一个“关键记忆”，把本章最重要的判断点收束起来。
2. “关键记忆”按本章 PDF 顺序排列，不按重要性随意打乱。
3. 每章末尾再放 5 道“思考题”，用于课堂提问或学生自测。
4. 思考题覆盖本章核心概念、容易混淆点、必要公式和最简单计算。
5. 思考题不要做成完整题库，题量保持克制，服务于复习课讲解。

## 6. 导出与检查

1. 修改 Markdown 后运行导出脚本生成 PDF。
2. 对新增图片较多的章节，渲染相关 PDF 页面检查版式。
3. 检查重点包括：目录层级是否干净、图片是否清楚、文字是否重叠、表格是否太挤、章节衔接是否自然。
4. 确认无明显排版问题后，再把新版 PDF 路径反馈给老师。
